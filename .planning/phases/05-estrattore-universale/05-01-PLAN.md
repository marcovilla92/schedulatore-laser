STRUTTURA FILE (in questo ordine):
1. Docstring modulo con descrizione e uso CLI
2. Import standard library: os, sys, time, json, pathlib.Path, datetime.datetime, typing (List, Literal)
3. Import Pydantic v2: BaseModel, Field (commento: "Pydantic v2 richiesto — dipendenza di Docling")
4. Import google-genai: from google import genai; from google.genai import types
   (commento: "Package: google-genai (NON google-generativeai che e EOL nov 2025)")
5. Import Docling in try/except: se fallisce, impostare _DOCLING_AVAILABLE = False con messaggio
6. Costante GEMINI_MODEL = "gemini-2.0-flash"
   (commento: "NOTA: gemini-2.0-flash va in pensione il 31 marzo 2026. Per migrare: 'gemini-2.5-flash'")
7. ExtractionError(Exception)
8. ConfidenceLabel = Literal["alta", "media", "bassa"]
9. ArticoloEstratto(BaseModel) con campi: codice, descrizione, quantita
10. OrdineEstratto(BaseModel) con campi:
    cliente, cliente_confidence, numero_ordine, numero_ordine_confidence,
    data_consegna, data_consegna_confidence, articoli, articoli_confidence
    (tutti i campi con Field(description=...) appropriato)
11. Funzioni private (in ordine):
    _build_docling_converter() -> DocumentConverter
    _extract_text_via_docling(filepath, converter, debug) -> str
    _build_gemini_client() -> genai.Client
    _build_prompt(markdown_text) -> str
    _call_gemini_with_retry(client, markdown_text, max_retries=3) -> OrdineEstratto
    _to_parser_compatible_dict(ordine) -> dict
12. extract_universal(filepath, debug=False) -> dict (funzione pubblica)
13. if __name__ == "__main__": block CLI

SPECIFICHE PER OGNI COMPONENTE:

_build_docling_converter():
- Tentare import di PyPdfiumDocumentBackend da docling.backend.pypdfium2_backend
- Se import fallisce (Docling 2.2.0 potrebbe non avere questo modulo), usare backend default
- Impostare do_ocr=False, do_table_structure=False su PdfPipelineOptions
- Restituire DocumentConverter con format_options per InputFormat.PDF
- Se Docling non e disponibile (_DOCLING_AVAILABLE=False), raise ExtractionError

_extract_text_via_docling(filepath, converter, debug):
- Chiamare converter.convert(filepath)
- Chiamare .document.export_to_markdown() sul risultato
- Se debug=True, stampare su sys.stderr: "[DEBUG] Testo Docling (primi 2000 car.):\n" + testo[:2000]
- In caso di eccezione, raise ExtractionError("Errore Docling su {filepath}: {e}")

_build_gemini_client():
- api_key = os.environ.get("GEMINI_API_KEY")
- Se None o stringa vuota: raise ExtractionError("GEMINI_API_KEY non configurata. Impostare la variabile d'ambiente.")
- return genai.Client(api_key=api_key)

_build_prompt(markdown_text):
- Istruire Gemini che "L.S. S.R.L." e il DESTINATARIO, NON il cliente
- Spiegare che cliente = azienda che EMETTE l'ordine (cerca nel logo, intestazione, "Spettabile"/"Spett.le")
- Formato data_consegna: ISO 8601 (YYYY-MM-DDTHH:MM:SS), stringa vuota se non trovata
- Confidence labels: "alta" = campo inequivocabile, "media" = ambiguo o parziale, "bassa" = deduzione
- Includere markdown_text alla fine dopo intestazione "## Documento da analizzare"

_call_gemini_with_retry(client, markdown_text, max_retries=3):
- Loop for attempt in range(max_retries):
  - Chiamare client.models.generate_content(model=GEMINI_MODEL, contents=prompt,
    config=types.GenerateContentConfig(response_mime_type="application/json",
    response_schema=OrdineEstratto, temperature=0.1))
  - Se response.text e None o vuoto: raise ExtractionError("Risposta Gemini vuota o None")
  - Validare con OrdineEstratto.model_validate_json(response.text)
  - Se ValidationError: raise ExtractionError("Risposta Gemini malformata: {e}")
  - Se errore 429/RESOURCE_EXHAUSTED: wait_time = 5 * (2**attempt), time.sleep(wait_time), continua
  - Altrimenti (errore non-429): raise ExtractionError immediato (non retry)
- Dopo loop esaurito: raise ExtractionError("Gemini non disponibile dopo {max_retries} tentativi: {last_exc}")

_to_parser_compatible_dict(ordine):
- Restituire dict con:
  cliente, numero_ordine, data_consegna (o datetime.now().isoformat() se vuota),
  data_ricezione=datetime.now().isoformat(),
  articoli=[{"code": a.codice, "name": a.descrizione, "qty": a.quantita} for a in ordine.articoli],
  quantita_totale=sum(a.quantita for a in ordine.articoli),
  cliente_confidence, numero_ordine_confidence, data_consegna_confidence, articoli_confidence,
  estrattore="universal"

extract_universal(filepath, debug=False):
- Docstring completa con Args/Returns/Raises
- Chiamare in sequenza: _build_docling_converter, _extract_text_via_docling, _build_gemini_client,
  _call_gemini_with_retry, _to_parser_compatible_dict
- NON catturare ExtractionError qui — lasciarla propagare al chiamante

if __name__ == "__main__":
- Fix encoding: if hasattr(sys.stdout, 'reconfigure'): sys.stdout.reconfigure(encoding='utf-8', errors='replace')
- Caricare app/.env: load_dotenv(Path(__file__).parent.parent / ".env")
- Controllare len(sys.argv) < 2: stampare uso su stderr e sys.exit(1)
- pdf_path = sys.argv[1]; debug_mode = "--debug" in sys.argv
- result = extract_universal(pdf_path, debug=debug_mode)
- print(json.dumps(result, indent=2, ensure_ascii=False))
