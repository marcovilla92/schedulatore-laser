- NOTA IMPORTANTE: ordini_estratti.html NON ha auto-refresh (carica su demand con "Aggiorna Elenco"). Quindi NON serve separazione fetch/render completa ne `hasDataChanged()`. Serve solo:
  - Variabili: `let allOrders = []; let searchQuery = '';`
  - Nella funzione `loadOrders()` esistente, dopo aver ricevuto i dati: `allOrders = orders; applyFiltersAndRender();`
  - `applyFiltersAndRender()` che filtra con una funzione wrapper:
    ```javascript
    function applyFiltersAndRender() {
      let filtered = allOrders;
      if (searchQuery.trim()) {
        const q = searchQuery.trim().toLowerCase();
        filtered = allOrders.filter(o =>
          (o.cliente || '').toLowerCase().includes(q) ||
          (o.numero_ordine || '').toLowerCase().includes(q) ||
          (o.id || '').toLowerCase().includes(q)
        );
      }
      updateActiveFilters();
      renderOrders(filtered);
    }
    ```
    NOTA: Usa un wrapper locale invece di `filterOrders()` da shared.js perche questa pagina filtra anche su `numero_ordine` (campo specifico di ordini estratti), non solo su `cliente` e `id`.
  - Search handler: `const debouncedSearch = debounce((q) => { searchQuery = q; applyFiltersAndRender(); }, 300);`
  - `function onSearch(value) { debouncedSearch(value); }`
