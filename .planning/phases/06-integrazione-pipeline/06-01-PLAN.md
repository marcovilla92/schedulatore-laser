<objective>
Integra l'estrattore universale nella pipeline Flask come percorso primario, con fallback automatico ai parser classici se Gemini non e disponibile.

Purpose: Senza questa integrazione, il lavoro di Phase 5 (universal_extractor.py) non viene mai usato in produzione — i PDF passano sempre per i parser classici. Con questa integrazione, qualsiasi PDF sconosciuto ha una seconda chance di estrazione prima di ricadere sui formati hardcoded.

Output: run.py carica app/.env all'avvio (GEMINI_API_KEY disponibile), app.py tenta extract_universal() prima di extract_pdf_content(), la risposta include il campo estrattore="universal" o estrattore="legacy".
</objective>

  <name>Task 2: Integrare extract_universal() in app.py con guarded import e fallback</name>
  <files>app/backend/app.py</files>
  <action>
In app/backend/app.py, effettuare due modifiche:

**Modifica 1 — Import guard a livello di modulo.**
Aggiungere dopo la riga "from .pdf_parser import extract_pdf_content" (riga 12 circa), PRIMA della definizione di Flask app:

```python
# Estrattore universale (Docling + Gemini 2.0 Flash) — importato con guard
# perche universal_extractor.py importa google.genai a livello modulo.
# Se google-genai non e installato, Flask si avvia comunque usando i parser classici.
try:
    from .universal_extractor import extract_universal
    from .universal_extractor import ExtractionError as UniversalExtractionError
    _UNIVERSAL_EXTRACTOR_AVAILABLE = True
except ImportError as _ue_import_err:
    _UNIVERSAL_EXTRACTOR_AVAILABLE = False
    print(f"[INFO] Estrattore universale non disponibile (ImportError): {_ue_import_err}")
```

**Modifica 2 — Sostituire la chiamata extract_pdf_content in extract_pdf_data().**
Nell'endpoint extract_pdf_data(), trovare la riga (circa riga 250):
```python
        pdf_data = extract_pdf_content(filepath)
```
Sostituire SOLO quella riga con il blocco seguente (mantenendo tutta l'altra logica intatta):

```python
        if _UNIVERSAL_EXTRACTOR_AVAILABLE:
            try:
                print(f"   -> Estrattore universale (Docling + Gemini)...")
                sys.stdout.flush()
                pdf_data = extract_universal(filepath)
                print(f"   OK Universale: {len(pdf_data.get('articoli', []))} articoli, estrattore={pdf_data.get('estrattore')}")
                sys.stdout.flush()
            except UniversalExtractionError as _ue_exc:
                print(f"   [FALLBACK] Universale non disponibile: {_ue_exc}")
                print(f"   -> Parser classici in uso...")
                sys.stdout.flush()
                pdf_data = extract_pdf_content(filepath)
                pdf_data["estrattore"] = "legacy"
        else:
            pdf_data = extract_pdf_content(filepath)
            pdf_data["estrattore"] = "legacy"
```
