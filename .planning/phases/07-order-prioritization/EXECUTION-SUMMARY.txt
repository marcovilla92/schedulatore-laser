================================================================================
TECHNICAL APPROACH
================================================================================

ALGORITHM: Earliest Due Date (EDD)
  - Sort orders by data_consegna (delivery date)
  - Ascending order (earliest deadline first)
  - O(n log n) complexity (JavaScript Array.sort)

IMPLEMENTATION LOCATION: Client-Side JavaScript
  - No backend API changes
  - No database schema changes
  - Timezone-safe (ISO 8601 + new Date())
  - Performance: <100ms for 50+ orders

KEY FUNCTIONS (4 total):
  1. getDaysRemaining(deliveryDate) -> number
  2. getUrgencyTier(daysRemaining) -> 'green'|'yellow'|'red'
  3. getUrgencyLabel(daysRemaining) -> "N giorni"|"Oggi"|"Scaduto"
  4. sortOrdersByEDD(orders) -> sorted array

CSS ADDITIONS (3 classes):
  • .urgency-badge.urgency-tier-green
  • .urgency-badge.urgency-tier-yellow
  • .urgency-badge.urgency-tier-red
  • .urgency-indicator (glowing dot)

DATA SOURCE:
  - order.data_consegna (from /api/phase/{PHASE}/orders)
  - Format: ISO 8601 DateTime (e.g., "2026-03-10T00:00:00")
