article_records_list = []
for art in articles_db:

    started_count = session.query(ProcessingStep).filter(
        ProcessingStep.article_id == art.id,

### Struttura HTML

**Modifiche alla tabella ordini:**
- Aggiungere una colonna "Fasi" (o sostituire la colonna "Azioni" esistente che attualmente ha solo un alert placeholder)
- Ogni riga ordine diventa espandibile: click sulla riga (o su un pulsante freccia) mostra/nasconde il pannello articoli
- Il pannello articoli si apre sotto la riga ordine come una riga aggiuntiva con colspan

**Pannello articoli espanso:**
Per ogni articolo (da `order.article_records[]`):
- Una riga con: nome articolo, codice, quantita
- 5 checkbox inline etichettate: LASER, PIEGA, SALDATURA, PULIZIA, SPEDIZIONE
- Checkbox checked se la fase e in `article.required_phases`
- Checkbox disabled + opacita ridotta se `article.has_started_steps === true`
- Un pulsante "Salva Fasi" per articolo (o per ordine intero — salva tutti gli articoli modificati)
- Se `has_started_steps === true`, mostrare un badge "In lavorazione" accanto al nome articolo

**Pulsante Salva:**
- Approccio per-ordine: un singolo pulsante "Salva Fasi" in fondo al pannello articoli
- Il pulsante e disabilitato se nessuna modifica e stata fatta
- Quando cliccato, per ogni articolo modificato, chiama `PUT /api/orders/{orderId}/articles/{articleId}/phases` con body `{"required_phases": ["LASER", "PIEGA", ...]}` (solo le fasi checked)
- Le chiamate API devono essere sequenziali (non parallele) per evitare conflitti
- Dopo il salvataggio di tutti gli articoli, mostrare feedback "Fasi aggiornate" (verde) o errore specifico

Il template HTML per ogni ordine deve essere qualcosa tipo:
```javascript
const articlesHtml = (order.article_records || []).map(article => {
    const PHASES = ['LASER', 'PIEGA', 'SALDATURA', 'PULIZIA', 'SPEDIZIONE'];
    const phases = article.required_phases || [];
    const disabled = article.has_started_steps;

    const checkboxes = PHASES.map(phase => {
        const checked = phases.includes(phase) ? 'checked' : '';
        const disabledAttr = disabled ? 'disabled' : '';
        const checkedClass = phases.includes(phase) ? 'checked' : '';
        const disabledClass = disabled ? 'disabled' : '';
        return `<label class="phase-checkbox ${checkedClass} ${disabledClass}">
            <input type="checkbox" value="${phase}" ${checked} ${disabledAttr}
                   data-article-id="${article.id}" data-order-id="${order.id}"
                   onchange="onPhaseCheckboxChange(this)">
            ${phase}
        </label>`;
    }).join('');

    return `<div class="article-row" data-article-id="${article.id}">
        <div class="article-info">
            <div class="article-name">
                ${article.name || 'Articolo'}
                ${disabled ? '<span class="badge-working">In lavorazione</span>' : ''}
            </div>
            <div class="article-code">${article.code || ''} ${article.qty ? '- Qty: ' + article.qty : ''}</div>
        </div>
        <div class="phase-checkboxes">${checkboxes}</div>
    </div>`;
}).join('');
```
