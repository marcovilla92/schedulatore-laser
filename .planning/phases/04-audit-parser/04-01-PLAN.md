**Struttura del file (in ordine):**

1. Intestazione + fix Unicode (PRIMA di qualsiasi print):
   sys.stdout.reconfigure(encoding='utf-8', errors='replace')

2. Import pattern (da batch_test_ordini.py esistente):
   sys.path.insert(0, str(Path(__file__).parent))
   from backend.pdf_parser import extract_pdf_content, detect_pdf_format
   import PyPDF2

3. Funzione get_pdf_format(filepath) — rileva il formato senza andare attraverso l'estrazione completa. Apre il PDF con PyPDF2, estrae il testo, chiama detect_pdf_format(text). Gestisce eccezioni restituendo 'UNKNOWN'. Reindirizza stdout durante il rilevamento per sopprimere i print del dispatcher.

4. Funzione evaluate_field(field_name, value, result) — restituisce 'PASS', 'FAIL', 'EMPTY', o 'FALLBACK':
   - cliente: FAIL se str(value).strip().lower() in {'', 'spettabile', 'l.s. srl', 'l.s. s.r.l.', 'ls srl', 'cliente sconosciuto'}
   - numero_ordine: FAIL se not str(value).strip()
   - articoli: PASS se len(result.get('articoli', [])) > 0, altrimenti FAIL
   - quantita: PASS se result.get('quantita_totale', 0) > 0, altrimenti FAIL
   - data_consegna: FALLBACK se il valore inizia con datetime.now().strftime('%Y-%m-%d') (significa che il parser ha usato datetime.now() come default); altrimenti PASS

5. Funzione audit_pdf(filepath) — esegue l'estrazione con stdout soppresso (redirect a io.StringIO), gestisce eccezioni per-PDF (try/except Exception) registrando CRASH con messaggio. Restituisce dict con chiavi: file, format, result, fields, error.

6. Funzione find_pdfs(directory) — usa pathlib per trovare tutti i file *.pdf e *.PDF nella directory specificata.

7. Funzione generate_report(results, directory, elapsed) — produce il testo del report:
   - Intestazione con data/ora, directory, totale PDF testati, tempo totale
   - Nota: "Nota: Docling fallback disabilitato (DOCLING_AVAILABLE=False in pdf_parser.py)"
   - Sezione PER-FORMAT SUMMARY: tabella con colonne Format | PDFs | cliente | numero_ordine | articoli | quantita | data_consegna
   - Per ogni formato: calcola % PASS per ciascun campo (FALLBACK conta come non-PASS)
   - Sezione PER-FILE DETAIL: una riga per PDF con [OK]/[FAIL]/[CRASH] + formato rilevato + stato per campo
   - Sezione BASELINE SUMMARY: overall success rates aggregati

8. Blocco main():
   - Parsing argomenti: --dir (default: C:/Users/39334/Documents/ORDINI)
   - Verifica che la directory esista
   - Crea app/audit_reports/ con Path.mkdir(parents=True, exist_ok=True)
   - Stampa progresso per ogni PDF durante l'audit ("Auditing 1/16: filename.pdf...")
   - Genera il report
   - Scrive il report su stdout E su file timestampato in app/audit_reports/audit_YYYYMMDD_HHMMSS.txt
   - Stampa il path del file salvato alla fine

**Criteri di classificazione per la colonna status nelle sezioni riepilogative:**
- [OK] = tutti e 5 i campi sono PASS (FALLBACK per data_consegna non conta come OK a livello di file)
- [PARTIAL] = almeno 1 campo PASS ma non tutti
- [FAIL] = 0 campi PASS o error nel result
- [CRASH] = exception non gestita durante l'estrazione

**NON modificare nessun file in app/backend/. NON riabilitare Docling.**
