  <action>
Aggiungi nuova classe ArchiveManager in database.py dopo AuditManager con questi metodi:

1. `_calculate_phase_times(order_id, session) -> dict`:
   - Query ProcessingStep per order_id
   - Per ogni fase (LASER, PIEGA, SALDATURA), calcola: end_time - start_time
   - Ritorna dict: {"LASER": "2h 15min", "PIEGA": "1h 30min", "SALDATURA": "3h 45min", "total_time": "7h 30min"}
   - Se fase non completata, ritorna None per quel campo
   - Usa OrderManager._format_duration() esistente

2. `get_completed_orders(filters=None, page=1, page_size=50, sort_by='data_completamento', sort_order='desc') -> dict`:
   - Query Order con status == 'SPEDITO'
   - Filtri opzionali: {'date_from': '2026-01-01', 'date_to': '2026-03-02', 'cliente': 'ABC Spa', 'phase': 'LASER'}
   - date_from/date_to filtrano su ProcessingStep.timestamp_fine (quando è stata completata l'ULTIMA fase)
   - cliente filtra su Order.cliente
   - 'phase' filtra ordini che hanno completato quella specifica fase
   - Ordina per: data_completamento (ultima fase completed), cliente, numero_articoli
   - Implementa pagination: offset = (page-1)*page_size, limit = page_size
   - Ritorna: {
       "total": 250,
       "page": 1,
       "page_size": 50,
       "orders": [
         {
           "id": "uuid-1",
           "numero_ordine": "ORD-2026-001",
           "cliente": "ABC Spa",
           "data_creazione": "2026-01-15T10:00:00",
           "data_completamento": "2026-01-20T16:30:00",  # timestamp della ULTIMA fase completata
           "tempi_per_fase": {"LASER": "2h 15min", "PIEGA": "1h 30min", "SALDATURA": "3h 45min"},
           "tempo_totale": "7h 30min",
           "numero_articoli": 45,
           "status": "SPEDITO"
         },
         ...
       ]
     }

3. `get_order_details(order_id) -> dict`:
   - Ritorna dettagli completi di un ordine: data_creazione, data_consegna, articoli[], tempi_per_fase, ProcessingStep con timestamp_inizio/fine per ogni fase
   - Formato risposta:
     {
       "id": "uuid-1",
       "numero_ordine": "ORD-2026-001",
       "cliente": "ABC Spa",
       "data_creazione": "2026-01-15T10:00:00",
       "data_consegna": "2026-01-25T00:00:00",
       "articoli": [...],
       "status": "SPEDITO",
       "tempi_per_fase": {
         "LASER": {"inizio": "2026-01-15T11:00:00", "fine": "2026-01-15T13:15:00", "durata": "2h 15min"},
         "PIEGA": {"inizio": "2026-01-15T14:00:00", "fine": "2026-01-15T15:30:00", "durata": "1h 30min"},
         "SALDATURA": {"inizio": "2026-01-15T16:00:00", "fine": "2026-01-15T19:45:00", "durata": "3h 45min"}
       },
       "tempo_totale": "7h 30min",
       "numero_articoli": 45
     }

4. `export_csv_data(filters=None) -> list`:
   - Esporta TUTTI gli ordini completati (non paginated) come lista di dict
   - Colonne: id, numero_ordine, cliente, data_completamento, LASER_time, PIEGA_time, SALDATURA_time, tempo_totale, numero_articoli, status
   - Formato tempo: "2h 15min" (leggibile CSV)

Note implementative:
- Usa session management pattern esistente (get_session(), try/finally)
- Tutti i timestamp sono DateTime, convertiti a .isoformat() in response JSON
- Se una fase non esiste (non è richiesta per ordine), omettila dal dict tempi_per_fase
- Performance: evita N+1 queries — load everything in single query se possibile, altrimenti usa efficient joins

Aggiungi 3 nuovi endpoint in app.py (dopo gli endpoint esistenti):

1. `GET /api/archive/orders` — Lista ordini completati con filtri
   - Query params:
     - `page=1` (default 1)
     - `page_size=50` (default 50)
     - `sort_by=data_completamento|cliente|numero_articoli` (default data_completamento)
     - `sort_order=asc|desc` (default desc)
     - `date_from=2026-01-01` (ISO format, optional)
     - `date_to=2026-03-02` (ISO format, optional)
     - `cliente=ABC Spa` (optional, substring match case-insensitive)
     - `phase=LASER|PIEGA|SALDATURA` (optional, filtra per fase completata)

   - Response (200 OK):
     JSON con structure da ArchiveManager.get_completed_orders()

   - Error handling:
     - If date_from > date_to: return 400 {"error": "date_from cannot be after date_to"}
     - If page < 1: return 400 {"error": "page must be >= 1"}
     - If page_size > 500: return 400 {"error": "page_size max 500"}
     - Any other exception: return 500 {"error": "..."}

2. `GET /api/archive/orders/<order_id>/details` — Dettagli completi singolo ordine
   - Path param: order_id (UUID string)
   - Response (200 OK): JSON da ArchiveManager.get_order_details(order_id)
   - Error handling:
     - If order not found: return 404 {"error": "Ordine non trovato"}
     - If order status != SPEDITO: return 400 {"error": "Ordine non completato"}
     - Any other exception: return 500 {"error": "..."}

3. `GET /api/archive/export/csv` — Esporta CSV tutti ordini completati
   - Query params (same as /api/archive/orders but no pagination):
     - `date_from`, `date_to`, `cliente`, `phase` (optional)

   - Response (200 OK):
     - Content-Type: text/csv
     - Header: "id,numero_ordine,cliente,data_completamento,LASER_time,PIEGA_time,SALDATURA_time,tempo_totale,numero_articoli,status"
     - Body: CSV rows (uno per ogni ordine completato)
     - Example row: "uuid-1,ORD-2026-001,ABC Spa,2026-01-20T16:30:00,2h 15min,1h 30min,3h 45min,7h 30min,45,SPEDITO"
     - filename: "archive_export_{timestamp}.csv" (e.g., "archive_export_2026-03-02_143000.csv")

   - Error handling:
     - Same as /api/archive/orders for filter validation
     - If no orders found: return 200 with empty CSV (solo header)

Implementation notes:
- Import ArchiveManager all'inizio di app.py
- Use request.args.get() per query params, con defaults
- Validate all dates with try: datetime.fromisoformat() except ValueError
- CSV generation: use Python's csv module or manual string concatenation
- For CSV filename, use datetime.utcnow().strftime('%Y-%m-%d_%H%M%S')
- All error responses return JSON, non HTML
