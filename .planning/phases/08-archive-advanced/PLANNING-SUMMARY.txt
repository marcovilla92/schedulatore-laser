KEY ARCHITECTURE DECISIONS
================================================================================

Backend:
  • ArchiveManager = static class (pattern consistent with UserManager)
  • No new database tables (uses existing Order + ProcessingStep)
  • No new dependencies (pure SQLAlchemy + Flask)

Frontend:
  • Vanilla JavaScript (no React/Vue/Svelte)
  • Inline CSS (single admin.html file)
  • Client-side state (archiveState global object)
  • Client-side pagination (50 items/page, OK for 1000 items)

Export:
  • CSV only (PDF can be added later with jsPDF)
  • Server-side generation (Python csv module)
  • Client-side download (blob + link)

Performance:
  • Single API call per load
  • No N+1 queries
  • Expected: < 2 sec for 100+ orders

Accessibility:
  • ARIA labels on all inputs
  • Keyboard navigation (Tab, Enter)
  • Semantic HTML structure
