Create `app/frontend/shared.js` as a **classic script** (NOT ES module). The file exposes 3 functions on the global `window` scope:

**1. `filterOrders(orders, query)`**
- Accepts an array of order objects and a search string
- Returns filtered array where `order.cliente` OR `order.id` contains the query (case-insensitive)
- Returns the full array if query is empty/null/whitespace
- Based on the filtering pattern in `archive.html`'s `applyFilters()` function

```javascript
function filterOrders(orders, query) {
  if (!query || !query.trim()) return orders;
  const q = query.trim().toLowerCase();
  return orders.filter(order =>
    (order.cliente || '').toLowerCase().includes(q) ||
    (order.id || '').toLowerCase().includes(q)
  );
}
```

**2. `debounce(fn, delay)`**
- Standard debounce: delays execution until `delay` ms after last call
- Returns a new function that wraps the original
- Preserves `this` context and arguments via `.apply()`

```javascript
function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

**3. `hasDataChanged(newData, lastHash)`**
- Compares JSON.stringify of new data against a previous hash string
- Returns `{ changed: boolean, newHash: string }`
- Based on the data comparison pattern in `laser.html` that prevents unnecessary re-renders during auto-refresh

```javascript
function hasDataChanged(newData, lastHash) {
  const newHash = JSON.stringify(newData);
  return { changed: newHash !== lastHash, newHash };
}
```

**File header**: Add an Italian comment block explaining this is a classic script loaded before page-specific scripts, and that these functions are available globally.

**DO NOT** use `export`, `import`, `type="module"`, or any module syntax. These are bare `function` declarations at the top level which automatically become `window.filterOrders`, etc.
